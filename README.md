# EZ-IGP: ICLR 2027 submission

This directory contains the double-blind ICLR 2027 submission source for
“Iterative Gumbel Planning for Continuous Control.”

Build with:

```bash
tectonic -X compile iclr2027_conference.tex --keep-intermediates --keep-logs
```

The generated PDF and LaTeX build products are intentionally ignored.
